

# 📅 ICS 课表导入 – 项目介绍

## 🎯 这是什么？

**ICS 课表导入** 是一个**纯静态网页工具**，能帮助您**一键识别学校教务课表**，并生成标准的 **ICS 日历文件**。  
有了它，您可以将课程表直接导入 Apple 日历、Google 日历、Outlook 等任何支持 iCalendar 格式的日历应用，再也不用手动抄写课表了！

## ✨ 核心亮点

- 🏫 **支持学校** – 自动从远程获取学校列表，无需手动更新，目前已覆盖广东岭南职业技术学院。
- 🔍 **一键智能识别** – 选择学校，点击“智能一键识别”，系统自动提取课表数据，无需复制粘贴。
- 📥 **动态脚本加载** – 识别逻辑实时从远程仓库获取，从而确保解析规则永远最新。
- 📆 **灵活设置学期** – 只需设定开学第一周的周一，所有课程自动按周次偏移。
- 📄 **标准 ICS 导出** – 生成符合国际标准的日历文件，兼容所有主流日历软件。
- ☁️ **云端分享** – 解析好的数据会自动生成一个url（链接）,方便你直接分享给你的朋友。

## 🚀 快速上手（3 步搞定）

1. **打开工具页** – 访问部署在 GitHub Pages 上的网页（或本地运行）。
2. **安装书签（一次性）** – 将页面上的 **“★ 识别课表”** 书签拖到浏览器收藏栏。
3. **登录教务 + 点击书签** – 在浏览器中登录学校教务系统，进入课表页面，点击收藏栏的书签，课表数据会自动回传到工具页，然后生成 ICS 文件并下载。

> 整个过程**无需安装任何扩展**，也**不需要复制粘贴**，数据仅在您的浏览器中处理，安全可靠。

## 🛠 技术栈（极简）

- **纯前端**：HTML + CSS + JavaScript，无后端依赖。
- **托管**：GitHub Pages，访问稳定。
- **文件分享**：tmpfiles.org API，免费且无需注册。

## ❓ 为什么不用其他方式？

- **无需扩展** – 书签方式轻量，跨浏览器兼容。
- **无需粘贴** – 数据通过 `postMessage` 自动回传，用户体验流畅。
- **适应 SSO** – 支持复杂的单点登录环境（如 SSO → 教务系统），登录在外部窗口完成，不受同源策略限制。

## 📌 适用场景

- 学生快速导入课表到手机/电脑日历。
- 分享课表给同学，一键生成链接。
